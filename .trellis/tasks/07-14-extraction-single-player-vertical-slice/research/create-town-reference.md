# Create Town Builder 参考观察

## Scope

2026-07-14 使用 Chrome 在 `https://create.town/builder` 进行只读视觉与 DOM 检查。本文只记录可观察体验特征，不提取或保存参考站点的贴图、字体、脚本或其他二进制资产。

## Observed Rendering

- 参考视口为 `2560 × 1294`，主 WebGL canvas 以 DPR 2 渲染为 `5120 × 2588`。
- 世界占满浏览器视口，没有固定产品顶栏、右侧认证面板或全屏场景遮罩。
- 第一人称镜头位于方块表面与建筑结构内部，近景方块占据大面积画面，产生明显身体尺度与空间在场感。
- 方块表面使用高频、低分辨率像素纹理；灰色石材通过多个近似明度的小色块形成颗粒感，而不是纯色材质。
- 页面在不同观察时刻出现明亮蓝天和暖色日落/雾景，说明天空颜色、距离雾和环境光是世界纵深的重要组成部分。
- 画面下方可见手部或手持方块 viewmodel；瞄准放置时可见半透明候选方块或目标反馈。

## Observed HUD

- 中央准星约 `16 × 16`，无外层面板。
- 顶部中央使用小型深色标签显示当前方块，例如 `Diorite (56)`。
- 底部快捷栏由独立 `368 × 48` canvas 绘制，位于视口水平中心，只占很低的垂直空间。
- 快捷栏使用深色槽位、浅色选中边框和小型像素物品图，不承载长说明文字。
- 右上角 Worlds 以无面板的轻量文字列表呈现；它体现参考产品的社区世界结构，但不属于 Extraction 单机模式的必要功能。
- DOM UI 使用 `ConnectionSerif-d20X, monospace`、16px 和接近白色文字。项目不得复制该字体文件；如需类似气质，应选择可用许可证字体或制作原创替代。

## Transferable Principles

- 世界是界面主体，HTML UI 只补充世界无法自然表达的信息。
- 用手部、工具、目标轮廓、材质变化和空间位置表达动作，不把所有反馈放进面板。
- 纹理密度、摄像机位置、近景比例和雾化纵深共同决定体素世界是否像“可进入的地方”。
- HUD 的质量来自尺寸克制、稳定锚点和与像素材质一致的视觉语言，不来自增加更多组件。

## Non-Transferable Elements

- Create Town 的品牌、世界名称、社区导航和聊天。
- 参考站点的原始纹理、字体文件、Logo、代码和其他受版权保护的二进制资产。
- 如果产品决定不加入建造，方块放置工具与 Builder 库存规则不应机械复制到 Extraction。
